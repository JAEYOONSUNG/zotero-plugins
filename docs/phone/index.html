논문

내 Zotero 라이브러리를 폰에서 읽고, 듣고, 정리합니다. 키는 이 폰에만 저장되고 어디로도 보내지 않습니다.

홈 화면 앱은 Safari와 저장 공간이 따로입니다. Safari에서 이미 연결하셨어도 여기서 키를 한 번 더 넣어야 합니다.

키는 zotero.org/settings/keys에서 만듭니다. Allow library access와 Allow write access를 켜 주세요. 쓰기를 켜야 폰에서 상태·별점·메모를 바꿀 수 있습니다.

홈 화면에 추가하면 키를 다시 넣어야 합니다. 키까지 함께 담기를 누른 뒤 공유 → 홈 화면에 추가를 하세요.
