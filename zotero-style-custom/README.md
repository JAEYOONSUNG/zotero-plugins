# Style Custom

Zotero 9용 개인 플러그인입니다. 메인 문헌 목록과 PDF 리더를 위한 연구 작업 패널, 그래프·태그·노트·주석·탭·뷰·캔버스·비교표 및 메타데이터 자동화를 제공합니다. 기존 ZotPoP와 별도 XPI로 설치합니다.

## 0.51.0 JCR 그룹 → 카테고리 → 저널

**저널 지표** 탭은 이제 JCR의 실제 **그룹별 카테고리** 화면으로 시작합니다. 그룹을 펼치고 카테고리를 누르면 그 카테고리에 속한 실제 JCR 저널 목록이 열립니다. 기존 OpenAlex 주제 탐색은 별도 버튼으로 선택할 수 있습니다.

- 원본 화면에서 수집한 **21개 그룹, 254개 카테고리, 22,643종 저널**과 다중 소속을 연결했습니다.
- 모든 카테고리의 저널 수를 원본과 대조했습니다. 카테고리별 공식 JIF 순위·Q·백분위를 그대로 표시하며 자체 계산으로 대체하지 않습니다.
- 이름·저널 수·JIF 등 정렬, 검색, 페이지당 25·50·75·100·200개, 뒤로가기를 제공합니다. 저널의 논문 검색은 ZotPoP로 연결합니다.
- JCR 2026 발표의 지표 연도 2025 자료입니다. 원본 갱신 표시는 2026-06-17, 화면 수집일은 2026-09-20입니다. 실시간 자동 갱신 데이터로 표시하지 않습니다.
- `<0.1` 같은 범위값과 `N/A`는 보존합니다. 그룹 카드의 저널 수는 JCR 원본 값이며, 여러 카테고리의 중복 소속이 포함될 수 있습니다.

[원본·화면·설치 검증 기록](../benchmark/jcr-native-browser-2026-09-20/REPORT.md).

## 0.50.3 저널 분류와 순위 (이전 변경 기록)

저널 탐색의 대분류·분야·세부 분야는 **OpenAlex 주제 분류**입니다. JCR 실제 화면에서 확인한 **21개 Group / 254개 Category**와 구분하며, 공식 JCR 카테고리 화면을 여는 버튼을 제공합니다. OpenAlex 분류와 저장된 JIF로 계산한 순위는 자체 비교임을 표시합니다. 카테고리가 기록되지 않은 기존 단일 Q값은 미확인 상태로 구분합니다.

- 같은 이름의 분야도 상위 경로가 다르면 분리합니다. 선택한 조건 전체가 한 경로에 속한 저널만 검색됩니다.
- 표시된 JIF가 같으면 같은 순위와 Q를 부여합니다. 선택한 분야와 다른 분야의 순위를 대신 표시하지 않습니다.
- 저장된 분류가 있으면 표·상세·필터·순위가 같은 분류를 사용합니다. 캐시의 첫 두 주제가 기존 분류를 덮어쓰지 않습니다.
- 새 분류 데이터 생성은 제공된 전체 주제와 식별자·출처를 보존하고, 저널 배열 순번에 의존한 예전 재개 자료의 잘못된 병합을 거부합니다. 기존 번들 자료는 새로 조회한 것으로 표시하지 않습니다.
- 백그라운드 설치는 검증한 파일의 내용과 기존 설치본의 변경을 확인합니다. 다른 설치본 변경을 감지하면 작업을 중지합니다.

0.50.3 당시에는 JCR 공식 카테고리 소속·순위·Q 전체가 연결되지 않았습니다. 0.51.0에서는 접근 가능한 JCR 원본 표를 수집·검증하여 위의 전용 탐색 화면에 연결했습니다. [이전 감사 근거](../benchmark/jcr-classification-audit-2026-09-20/REPORT.md).

## 사용

- 긴 제목에 마우스를 올리면 200ms 뒤 초당 180px로 스크롤합니다. 벗어나면 원위치로 돌아옵니다. 서식과 아이콘을 유지하며 시스템의 동작 줄이기 설정을 따릅니다.
- `Read Time · Custom`은 활성 PDF에서의 입력 이후 읽기 시간을 기록합니다. 백그라운드와 60초 이상 무활동은 제외합니다. 별도 PDF 창도 지원합니다.
- `Status · Custom`은 읽기 시간이 있으면 `reading`, 완료 태그가 있으면 `done`을 표시합니다. 시간만으로 완료 처리하지 않습니다.
- 문헌 우클릭 → **Style Custom**에서 상태와 별점을 지정합니다. 별점 열의 별을 클릭해도 됩니다. 같은 별을 다시 누르면 별점을 지웁니다.
- **커스텀 열로 전환**은 기존 Style의 대응 열을 숨기고 새 열 6개를 표시합니다. 열 제목 우클릭으로 표시·숨김과 너비를 조절할 수 있습니다.
- Zotero 설정 → **Style Custom**에서 롤링 속도, 시간 기록, 상태 연동을 변경합니다.


## 0.8.0 상세 환경설정·읽기 시간·아이콘

기능 존재와 상세 설정 지원을 구분했습니다. Style Custom 환경설정에 **열 / 뷰·작업 패널 / 리더·주석 / 사이드바·탭 / 태그 / 컬렉션 / 메뉴·디자인 / 읽기 기록 / 인용 수·IF / 번역·AI** 10개 분류를 제공합니다. 설정 검색, 항목별 설명, 적용·오류 표시, 분류 기본값 복원을 지원하며 API 키는 가려 표시하고 분류 복원으로 지우지 않습니다.

- 열 표시 스위치는 실제 열 등록을 켜고 끕니다. 리더·작업 패널의 기능 스위치도 실제 진입점과 효과에 적용합니다.
- Read Time은 기본 `0s`부터 표시하고 활성 읽기 중 기본 1초마다 갱신합니다. 저장 완료를 기다리지 않고 화면부터 갱신합니다. 간격·무활동 제외·시간 형식을 조절할 수 있습니다.
- PDF 테마·사용자 색상, 여백 위치·너비·글자 크기·텍스트 길이, 인용문·메모 및 주석 유형 표시를 직접 조절합니다.
- 목록·비교표 크기, 상세 발췌 수, 태그 표시 방식, 날짜 표현, 인용 수 재조회 간격, AI 출력 언어·지시문을 제공합니다.
- 문서와 인용 연결을 표현한 무채색 아이콘을 플러그인 목록·환경설정·워크벤치에 연결했습니다.

[상세 환경설정 미리보기](docs/settings-preview.html), [실제 설정별 소비 코드](docs/settings-coverage.json), [0.8.0 변경·검증 기록](docs/settings-0.8.0.md). 원본의 모든 서비스·옵션을 그대로 복제했다고 주장하지 않습니다. IF는 검증된 카탈로그·저장값 자동 매칭이며 공식 페이지 재조회는 명시적 실행입니다. Google Scholar/CNKI·원본 노트 동기화 저장 방식·자동 번역은 이 설정 화면에 작동하는 옵션처럼 노출하지 않습니다.

## 0.7.1 장식 제거

기본 화면을 흰색·회색 중심으로 정리했습니다. 보라/금색 UI 강조, 큰 둥근 모서리, 그림자, 캔버스 점무늬, 장식용 글꼴을 제거했습니다. 별점은 금색 대신 일반 글자색으로 표시하며, 읽기 진행률·태그·주석의 의미 있는 색상과 사용자 데이터는 유지합니다. [현재 미리보기](docs/design-preview.html)에 반영했습니다.

## 0.7.0 디자인과 사용성

연구 작업 패널을 탐색·읽기·정리·도구의 네 그룹으로 묶고, 제목·저자·지표의 시각적 우선순위를 정리했습니다. 라이트/다크 모드, 좁은 패널과 낮은 창에 대응하며 간격을 넓게/좁게 바꿀 수 있습니다. 마지막 사용 메뉴와 화면 밀도는 로컬에 기억합니다.

- 상세 필터는 접어서 공간을 확보하고, 활성 필터는 개별 해제할 수 있습니다. 노트·주석·첨부 검색에도 부모 문헌의 필터가 적용됩니다.
- 패널 안에서 **⌘/Ctrl+K**로 기능을 찾아 이동합니다. **/** 또는 **⌘/Ctrl+F**는 문헌 검색에 포커스를 옮기고, **Esc**는 기능 찾기부터 닫은 뒤 패널을 닫습니다. 편집 중 `/` 입력은 가로채지 않습니다.
- 선택 문헌 수와 현재 결과 밖에 있는 선택을 표시하고, 문헌 두 개가 필요한 연결 버튼은 선택 조건을 충족할 때 활성화합니다.
- 저장 중 상태를 표시하며 화면이 갱신돼도 같은 노트가 중복 생성되지 않습니다. 저장만으로 편집기를 열지 않고 **저장한 노트 열기**를 별도 제공합니다.
- 많은 노트·주석은 개수와 첫 다섯 항목을 보여주고 더 펼칠 수 있습니다. 미리보기 불가 첨부는 열기 안내를 제공합니다.

[오프라인 디자인 미리보기](docs/design-preview.html)는 실제 패널 코드와 예시 문헌을 사용합니다. 실제 Zotero나 사용자 라이브러리에 연결하지 않습니다. [디자인 검증과 범위](docs/design-0.7.0.md)를 참고하세요.

## 0.6.0 기능 보완 — 18회 개선

설치된 Style 6.0.76을 다시 대조하면서 18개 기능 개선 라운드를 진행했습니다. 이전 목록에서 누락된 `reader.mergeAnnotations`와 `reader.attachmentVersionSwitch`를 포함해 원본 기능 스위치 50개를 확인했습니다.

- 문헌 탐색: 현재 컬렉션·하위 컬렉션, 상태·별점·연도 필터, 정렬, 100개씩 페이지 탐색, 페이지/검색 결과 선택. 단일 문헌 상세에 노트와 주석을 함께 표시합니다.
- 태그·주석: 선택 문헌의 태그 경로 변경·병합, 주석 색상 일괄 편집, 같은 PDF의 하이라이트/밑줄 병합, 주석별 참조 노트 조회. 주석 열에서 페이지별 색상 분포와 원문 이동을 제공합니다.
- 탭·뷰: 탭 순서 이동, 다른 문서 탭 닫기, 저장 그룹 이름·내용 갱신, 같은 문헌의 PDF 버전 전환.
- 리더: 원래 모양 복원, 여백 주석의 위치·너비·표시 길이 설정, 주석 머리글의 참조 노트 수와 이동 메뉴.
- 캔버스·비교: 보드·카드 이름과 색상 편집, 카드 연결 해제, 비교 항목 선택·저장, 화면 페이지 이동과 전체 CSV 복사.

[기능 대조표](docs/feature-parity.md)와 [18회 코드·테스트·진입점 기록](docs/improvement-rounds.json)에 세부 범위가 있습니다. 실제 앱 활성화와 화면 검증은 수행하지 않았습니다. 주석 병합은 기존 노트 링크를 자동으로 다시 쓰지 않으며, PDF 버전 전환은 기존 탭을 유지합니다.

## 0.5.1 안정성 개선

메모·노트 저장 중 이어 쓴 초안을 보존하고, 이전 저장 실패가 이후 메모를 되돌리지 않도록 했습니다. 캔버스 선택 표시와 실제 작업 대상을 일치시켰습니다. 아직 로드되지 않은 탭도 저장한 페이지로 복원하며, 창이 닫히면 복원을 중단합니다. 읽기 종료 직전의 짧은 시간도 한 번만 기록합니다.

AI 요청 취소를 즉시 처리하고, 삭제된 문헌 하나 때문에 전체 메타데이터 작업이 중단되지 않도록 했습니다. 창 종료 중 네트워크 재시도가 멈추거나 일부 정리에 실패해 등록 기능이 남는 경우를 수정했습니다. 앱 밝기 전환과 읽을 때 수정일 갱신 옵션도 작업 패널에 연결했습니다. [수정·검증 기록](docs/hardening-0.5.1.md)을 참고하세요.

## 0.5.0 연구 작업 패널

도구모음 **워크벤치**, 문헌 우클릭 **연구 작업 패널**, 또는 PDF 리더의 **Style** 메뉴에서 사용합니다. 창을 자동으로 열거나 포커스를 가져오지 않으며 요청할 때 패널을 표시합니다.

- **문헌 탐색·최근 문헌:** 검색·유형·태그 필터, 상세 초록, 메모, 최근 읽기·수정 정렬.
- **관계 그래프·중첩 태그:** 관련 문헌, 공통 저자·태그의 연결, 계층 태그 탐색, 선택 문헌에 정확한 태그 추가·제거.
- **노트·주석·역링크:** 범위별 검색, 네이티브 리치 노트 편집, 원문 위치 이동, 출처를 유지한 주석의 노트 추출.
- **첨부 미리보기:** Zotero의 첨부 미리보기 컴포넌트와 파일 열기.
- **읽기 진행:** PDF별 페이지 시간을 분리해 저장, 전체 페이지 범위 탐색, 제목 히트맵. 이전 기록의 첨부파일을 알 수 없으면 임의의 PDF로 연결하지 않습니다.
- **PDF 도구:** 밝게·어둡게·세피아·사용자 색상, 분할 화면 양쪽 여백 주석, 색상 이름·팔레트, 리더 사이드바와 독립 세로 탭 목록.
- **탭·뷰 그룹:** 안정적인 문헌 키로 탭과 위치 저장·복원, 열 순서·너비·표시·정렬 저장·복원.
- **캔버스·비교표:** 문헌·메모 카드 배치·연결·편집, 보드 삭제·되돌리기, 논문 비교 행·열 전환과 CSV 복사.
- **컬렉션·스타일:** 개수·즐겨찾기·정렬, 메뉴 표시 설정, 앱 밝기 전환, 추가 필드 열, 범위가 제한된 CSS 편집.
- **번역·AI:** 설정한 Chat Completions 호환 모델에 제목 번역·초록 요약·읽기 메모·태그 제안을 요청하고, 결과 확인 후 적용. API 키와 모델은 자동으로 설정하지 않습니다.

기본 6개 열을 유지하고 진행률·메모·발행처·기여자·날짜·번역·요약·주석 수 등의 추가 열은 숨긴 채 등록합니다. 열 제목 우클릭으로 필요한 열을 표시하세요. 작성 중 초안은 제한된 로컬 저장 공간에 보관하며 다른 문헌·라이브러리에 적용하지 않습니다.

현재 0.6.0에서는 원본 설정 스위치 50개와 추가 워크플로 7개를 대조했습니다. [대응표](docs/feature-parity.md)는 실제 진입점·구현·테스트·외부 의존 조건을 명시합니다. 이는 원본의 모든 화면과 세부 설정이 동일하다는 뜻은 아닙니다.

### 백그라운드 업데이트

`scripts/install-background.py`는 이미 등록된 이 플러그인만 갱신합니다. Zotero가 실행 중이면 대기하고, 완전히 종료된 뒤 검증된 XPI 해시를 재확인하여 백업 후 교체합니다. 앱을 종료·실행하거나 창을 띄우지 않습니다. `extensions.json`과 다른 플러그인 활성화 설정은 유지합니다. 다음 정상 실행 전까지 새 버전의 활성화는 확인되지 않습니다. 대기 프로세스는 최대 24시간 유지되며, 취소 파일로 중지할 수 있습니다. 상태 파일에 PID·대기 여부·최종 확인 시간을 기록하고, 제한 시간이 지나면 `timed-out`으로 표시합니다. 여러 업데이트가 겹치면 잠금을 획득한 뒤에도 설치 버전을 다시 확인하여 최신 버전을 보존합니다.

## 기존 데이터와 저장

기존 `/unread`, `/reading`, `/done`, 별 태그와 Extra의 Rating을 인식합니다. 수동 상태·별점 변경은 기존 관련 태그만 갱신하고 다른 태그와 문헌 필드는 보존합니다. 별점의 명시적 삭제는 `style-custom:rating:0` 태그로 구분합니다.

수동으로 `unread`를 지정하면 기존 읽기 시간은 지우지 않고 이 컴퓨터에서 상태만 재설정합니다. 새 읽기 활동이 기록되면 다시 `reading`이 됩니다. 완료 태그는 자동 전환보다 우선합니다.

읽기 시간과 지표 스냅샷은 Zotero 데이터 폴더의 `style-custom.json`에 저장됩니다. 이 파일은 Zotero의 기본 동기화 대상이 아닙니다. 상태·별점 태그는 일반 Zotero 동기화를 따릅니다.

기존 Style이 활성화되어 있으면 표시하는 문헌의 읽기 기록을 읽어 자체 스냅샷에 보관합니다. 기존 `zoterostyle.json`의 IF와 기본 사용자 라이브러리 인용 캐시도 읽습니다. 문헌 Extra에 출처가 있는 인용 수가 있으면 그 값을 우선하고, 툴팁에 출처를 표시합니다. 인용 수의 제공기관·조회일 차이로 기존 Style과 숫자가 다를 수 있습니다. 식별자가 겹칠 수 있는 그룹 라이브러리에는 항목 키만으로 이전 인용 캐시를 적용하지 않습니다.

IF는 출판사 공식 자료 86종을 담은 카탈로그와 저널명·명시적 별칭·ISSN 매칭을 우선 사용합니다. 2024·2025 JIF의 연도와 원문 출처, 확인일을 툴팁에 표시합니다. 공식 페이지가 연도를 밝히지 않은 9종은 “연도 미표기”로 구분합니다. 확인된 카탈로그 값이 이전의 연도 없는 Style 캐시보다 우선합니다. 인용 수는 OpenAlex DOI 묶음 조회를 우선하고, Crossref의 정확 DOI 조회로 보완합니다. DOI가 없으면 제목·연도·첫 저자가 모두 일치하는 경우만 사용합니다. 숫자 문자열로 저장된 기존 Style 인용 수도 인식합니다.

문헌 우클릭 → Style Custom → **선택한 저널 IF를 공식 페이지에서 새로고침**은 등록된 공식 HTML 페이지 또는 Cell Press CSV에서 JIF를 다시 확인해 저장합니다. 페이지 구조·접근 제한·PDF 자료 때문에 검증하지 못하면 기존 값을 유지하고 실패 개수를 알립니다. 미등록 저널을 검색엔진에서 자동 추측하지는 않습니다.

IF를 확인하지 못한 항목은 `—`와 이유 툴팁을 표시합니다. 저널명이 없는 프리프린트·책·데이터셋 등에 임의로 저널 IF를 붙이지 않습니다. CiteScore를 IF로 바꾸거나 모르는 값을 0으로 채우지 않습니다. 기존 Style과 동시에 시간을 기록할 때는 두 누적 시간 중 큰 값을 사용해 중복 합산하지 않습니다.

기존 Ethereal Style을 제거하거나 비활성화하지 않습니다. 제목 롤링, 새 읽기 시간 기록, 상태·별점·태그 및 보관된 지표 표시는 Style 없이도 동작합니다. 0.6.0의 기능별 대응과 조건은 [기능 대조표](docs/feature-parity.md)에 있습니다. 원본과 다른 UI로 재구현했으며, 외부 AI·등급 데이터 서비스는 별도 설정이 필요합니다.

## 설치와 검증

빌드 파일: `build/style-custom-0.51.0.xpi`. 검증한 XPI를 별도 대기 파일로 보관하고, 이미 설치된 플러그인은 위의 백그라운드 업데이트로 교체합니다. 현재 빌드·설치·활성화 상태는 [설치 기록](docs/installation-status.json)과 그 안의 실시간 상태 파일을 구분해 확인하세요. 실제 자동 업데이트 서버는 없으며 매니페스트의 `updates.invalid`는 Zotero가 요구하는 HTTPS 필드용 예약 도메인입니다.

```sh
npm test
npm run build
npm run smoke               # background Node/DOM checks
npm run test:installer      # temporary fake-profile filesystem checks
npm run verify:features     # all 50 simple/dotted baseline feature mappings
npm run verify:improvements # at least 10 distinct code/test/entry-point records
```

0.7.0 검증은 사용자 UI를 띄우지 않는 Node/DOM 및 파일시스템 테스트입니다. `smoke:native`는 별도 앱 인스턴스를 실행할 수 있어 이번 작업에서는 실행하지 않았습니다. 기존 `docs/smoke-result.json`은 이전 버전의 역사적 기록이며 0.7.0 네이티브 검증 근거가 아닙니다.

사용 중인 기본 라이브러리의 상위 문헌 중 저널명이 있는 1,116개를 실제 런타임으로 비교했습니다. IF 표시 가능 항목은 231개에서 863개로 증가했습니다. 253개는 확인된 값이 없어 남아 있습니다. 이 수치는 특정 라이브러리의 적용 결과이며 모든 저널의 완전한 지표 데이터베이스를 의미하지 않습니다. [측정 기록](docs/if-coverage.json)에 조건과 잔여 저널 예시가 있습니다.

## 0.4.1 인용 수와 메타데이터 자동화

논문이 추가되거나 메타데이터가 변경되면 약 1.2초 동안 연속 변경을 모은 뒤, 인용 수를 백그라운드에서 조회하고 Extra에 저장합니다.

`Citations: 123 (OpenAlex, 2026-09-13)`

DOI가 같고 최근에 확인한 값은 캐시를 재사용합니다. 다른 Extra 내용은 보존하고, 편집 중인 문헌을 덮어쓰지 않습니다. 자체 저장 알림은 재조회하지 않습니다. 이 동작은 Zotero 설정 → Style Custom → **논문 추가·메타데이터 갱신 시 인용 수를 함께 조회해 Extra에 저장**에서 조절합니다. 별도의 코드 실행 창이 필요하지 않습니다.

처음 업그레이드할 때는 이미 확인된 캐시의 인용 수를 기본 라이브러리 Extra에 한 번 저장합니다. 이 이관에서는 새 네트워크 전수 조회를 하지 않습니다. 원본 제공자가 불명확한 기존 Style 캐시 값은 임의로 OpenAlex/Crossref라고 표기하지 않습니다.

목록에 보이는 문헌도 자동 조회하며, 성공한 결과는 7일, 미일치는 1일, 조회 오류는 30분간 같은 요청을 반복하지 않습니다. 식별자가 바뀌면 이전 논문 결과를 재사용하지 않습니다. 정확한 0과 미확인 `—`, 조회 중 `…`를 구분합니다. 오류 시 마지막 확인값을 보존하고 툴팁에 실패 여부를 표시합니다.

우클릭 → Style Custom의 **선택한 문헌 인용 수 새로고침**, **인용 수 조회 중지**, **현재 라이브러리 인용 수 조회·메타데이터 저장**으로 직접 실행할 수도 있습니다. OpenAlex 키와 연락 이메일은 선택 사항입니다. 제공자마다 집계 범위가 달라 수치가 다를 수 있으며, 출처를 합산하지 않습니다.

실제 적용 결과: 기본 라이브러리 1,214개를 처리해 인용 수 표시가 319개에서 1,158개로 증가했습니다. 제공자까지 확인된 1,150개는 Extra 저장을 마쳤고 저장된 SQLite에서도 대조했습니다. 8개는 제공자 미상의 이전 캐시 값만 유지하며, 56개는 계속 미확인입니다. [측정·저장 검증 기록](docs/citation-coverage.json)을 참고하세요.
