# 리더 패널 디자인 미리보기

[reader-preview.html](reader-preview.html) — Zotero 없이, 네트워크 없이, 화면에 창 하나 띄우지 않고 리더 패널
(`src/reader-assist.js`)을 그대로 그려 둔 파일입니다. 예시 논문 한 편만 들어 있고 실제 라이브러리는 건드리지
않습니다.

```sh
npm run preview:reader                                    # docs/reader-preview.html 를 다시 만든다
node scripts/preview-shots.mjs /tmp/shots reader light 2000 880   # 헤드리스 크롬으로 사진 (창 안 뜸)
node scripts/preview-shots.mjs /tmp/shots reader dark  2000 880
```

`PREVIEW_PAGE=file://…/docs/reader-preview.html` 를 주면 `preview-shots.mjs` 가 이 파일을 찍습니다.

다섯 가지 상태를 한 줄에 놓고 비교하도록 만들어져 있습니다. 카드 하나만 떼어 보면 간격이나 글자 굵기가
맞는지 알 수 없기 때문입니다.

| | |
|---|---|
| AI 요약·대화 | 요약 카드와 대화 입력 |
| 번역 | 문단별 번역의 선택지와 결과 |
| 듣기 · 운전용 오디오 | 문장 목록과, 아직 만들지 않은 오디오 카드(예상 분량·용량·걸리는 시간) |
| 듣기 · 만드는 중 | 진행 막대, 만든 문장 수, 취소 |
| 듣기 · 완성 | 길이·용량과 파일이 들어간 폴더 |

## 이 미리보기로 고친 것 (0.59.48)

- **속도 라벨이 "속/도"로 세로로 깨지던 것** — 패널 너비 372px에서 목소리 알약에 밀려 두 줄이 되고 있었습니다.
  라벨은 줄바꿈하지 않습니다.
- **목소리 알약이 잘리던 것** — "Supertonic 3 · F3 (clear n…" → 알약은 목소리 이름까지만, 설명은 메뉴에서.
- **슬라이더와 체크 상자가 시스템 파랑이던 것** — 조용한 패널에서 혼자 튀었습니다. `accent-color` 로 패널
  자신의 링크 색을 씁니다.
- **운전용 오디오가 버튼 하나와 글자 한 줄이던 것** — 몇 분 걸리는 일을 설명하지 못했습니다. 카드로 바꾸고,
  누르기 전에 분량·용량·걸리는 시간을 먼저 말하고, 만드는 동안 막대와 취소를 둡니다.
