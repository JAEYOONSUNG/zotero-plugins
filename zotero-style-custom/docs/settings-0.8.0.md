# Style Custom 0.8.0 — 상세 설정·읽기 시간·아이콘

이전 기능 대조표는 기능 실행 경로와 테스트를 확인한 자료였습니다. 이를 원본의 상세 환경설정까지 완성한 것처럼 설명한 것은 부정확했습니다. 기존 Custom 환경설정은 짧은 그룹 몇 개뿐이었으며, 새 작업 패널의 세부 기능도 직접 설정하기 어려웠습니다.

이번에는 **10개 분류, 저장 설정111개, 명시적 실행6개**를 실제 런타임에 연결했습니다. 50개 원본 기능의 표시/사용 스위치를 포함합니다. [항목별 소비 코드](settings-coverage.json)와 [작동하는 예시 설정 화면](settings-preview.html)을 제공합니다.

- **열:** IF·인용 수·읽기 시간·별점·날짜 등 등록/해제, 시간 형식, 0초 표시, 날짜 상대 표시, 추가 필드, 제목 롤링·태그·강조.
- **뷰·패널:** 메뉴별 기능, 화면 밀도, 목록·비교표 페이지 크기, 처음 표시할 노트/주석 수와 발췌 길이, 그래프 문헌 수, 주석 Figure/Table 제외와 메모 우선 표시.
- **리더·사이드바:** 테마/사용자 색상, 여백 위치·너비·글꼴·텍스트 길이, 인용문/메모, 여섯 주석 유형, 사이드바·세로 탭, 병합·버전 전환·역링크 기능.
- **태그·컬렉션·메뉴:** 태그 표시 대상/접두사/제목 표시 수, 개수·즐겨찾기·정렬, 패널 글꼴·CSS와 개별 기능.
- **읽기 기록:** 기본1초 간격, 0s 표시, 무활동5–300초, 자동 상태 연동 및 선택적인 수정일 갱신. 화면은 저장 완료 전에 갱신합니다. 상태·제목 스크롤 설정을 바꿔도 읽기 타이머를 다시 시작하지 않습니다.
- **지표·AI:** 인용 수 조회·저장, 재조회·오류 재시도 간격, 실제 제공자 키, 모델/endpoint/출력 언어/태그·메모 지시문. 분류 초기화는 비밀번호·API 키를 보존합니다.

원본의 모든 외부 제공자·장식 옵션·자동 번역·노트 동기화 저장 방식까지 동일하게 복제됐다는 의미는 아닙니다. 없는 기능을 작동하는 설정처럼 노출하지 않았습니다. IF는 검증된 카탈로그/저장값 자동 매칭이며 공식 페이지 새로 조회는 명시적 실행입니다. 열 표시와 기록 여부는 별도 설정입니다.

**Read Time 검증:** 실제 Runtime+DOM에서 처음0s, 읽기1초가 누적되면1s가 표시되고 파일 저장이 대기 중이어도 셀과 패널 숫자가 바뀝니다. 기록 간격/무활동 변경은 읽기 시계를 재설정하지만 상태·스크롤·글꼴 변경은 시계를 불필요하게 초기화하지 않습니다. 단순한 샘플 숫자를 실제 기록인 것처럼 표시하지 않습니다.

**아이콘:** 문서와 인용 연결을 결합한 무채색 원본 벡터를 만들었습니다. [SVG](../content/icons/style-custom.svg), [PNG128](../content/icons/style-custom-128.png). 16·24·32·48·96·128·256px을 생성했고 플러그인 manifest, 환경설정의 image, 워크벤치 툴바와 헤더에 연결했습니다. 이미지 생성 서비스나 다른 플러그인의 도안을 복사하지 않았습니다.

**검증:** Node/DOM/리더/설정 298개, 임시 프로필 설치기11개 통과. 기준6개 충족, 미충족0개, 포기0개. 두 독립 에이전트의 설정 UI·리더 검증을 다시 실행하고, 실제 설정 체크박스가 열을 해제하는 통합 검사와 기능을 꺼도 다른 버튼으로 실행되는 우회 경로 검사를 포함했습니다. XPI 파일29개가 소스와 일치합니다.
