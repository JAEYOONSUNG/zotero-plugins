# Style Custom 0.6.0 — 18회 기능 개선

기능별로 구현·회귀 테스트·검토를 진행한 18개 라운드입니다. 두 에이전트가 데이터와 리더 기능을 나눠 구현했고, 루트에서 모든 사용자 진입점을 연결하고 전체 테스트를 다시 실행했습니다. 주석 병합의 데이터 처리와 리더 메뉴는 같은 라운드로 세었습니다. 추가 오류 수정이나 테스트 재실행을 별도 라운드로 부풀리지 않았습니다.

| 회차 | 실제 개선 | 진입점 |
|---|---|---|
| R01 | 선택 문헌의 중첩 태그 이름 변경·병합 | 중첩 태그 → 선택 문헌 태그 이름 변경 |
| R02 | 주석 색상 일괄 편집 | 주석 → 선택 주석 색상 변경 |
| R03 | 선택 문헌 간 관련 링크 해제 | 패널 하단 → 선택 문헌끼리 연결 해제 |
| R04 | 현재 컬렉션·하위 컬렉션 범위 | 표시 범위 → 현재 컬렉션·하위 컬렉션 |
| R05 | 탭 순서 이동·다른 문서 탭 닫기 | 탭 관리·세로 탭 → 순서 이동·다른 탭 닫기 |
| R06 | 저장 탭 그룹 이름·내용 갱신 | 탭 관리 → 그룹 이름 변경·현재 탭으로 갱신 |
| R07 | 저장 뷰 이름·열 배치 갱신 | 뷰 그룹 → 이름 변경·현재 배치로 갱신 |
| R08 | 리더 모양 복원·여백 주석 표시 설정 | 읽기 진행 / PDF Style → 모양 복원·여백 설정 |
| R09 | 읽기 상태·별점·연도 필터와 정렬 | 워크벤치 상단 상세 필터 |
| R10 | 200개 제한을 넘는 탐색·페이지/결과 선택 | 문헌 탐색 → 이전/다음 페이지·검색 결과 전체 선택 |
| R11 | 비교 항목 선택·저장·전체 결과 CSV | 논문 비교 → 비교 항목 선택·CSV 복사 |
| R12 | 보드·카드 이름·색상·연결 편집 | 캔버스 → 보드 이름 변경·카드 편집·카드 연결 해제 |
| R13 | 정확한 주석별 참조 노트 조회 | 주석 → 참조 노트 보기 |
| R14 | PDF 주석 머리글 역링크 수·노트 열기 | PDF 주석 머리글 → 참조 노트 개수·노트 열기 |
| R15 | 같은 페이지·인접 두 페이지 주석 병합 | PDF 주석 우클릭·Style 메뉴 / 주석 → 선택 주석 병합 |
| R16 | 같은 문헌의 PDF 첨부 버전 전환 | PDF Style → Switch PDF version |
| R17 | 문헌 상세에 상태·노트·주석 함께 표시 | 문헌 탐색 → 자세히 |
| R18 | 주석 열의 페이지별 색상 분포·원문 이동 | Annotations · Custom 색 막대 |

최종 검증은 Node/DOM **249개**, 임시 프로필 설치기 **11개** 통과입니다. 완료 기준은 **6개 충족, 미충족 0개, 포기 0개**입니다. 원본의 실제 설치 버전 6.0.76에서 일반 이름과 점이 포함된 이름을 모두 추출해 **50개 기능 스위치 + 추가 워크플로 7개**를 대조했습니다. 이전 목록이 빠뜨린 `reader.mergeAnnotations`와 `reader.attachmentVersionSwitch`를 제거하면 검증기가 실패하는 음성 대조도 포함했습니다.

최종 통합 검토에서 비교 항목을 빠르게 해제할 때 변경이 되돌아오는 문제와 컬렉션 조회 중 선택이 바뀌었을 때 오래된 결과가 남는 문제를 재현하고 수정했습니다. PDF 버전 조회 중 부모 삭제·첨부 이동·라이브러리 변경도 다시 검증합니다.

XPI의 런타임 파일 **18개**를 소스와 바이트 단위로 대조했습니다. SHA-256: `73742410f659c41191ca3143070e161426213f043f9a32998c8a45509b3a454a`.

사용자 화면을 제어하거나 Zotero를 추가 실행하지 않았습니다. 이전 업데이트는 취소 응답을 확인했고, 새 파일은 별도 프로세스가 최대 24시간 동안 Zotero의 정상 종료를 기다렸다가 백업 후 교체합니다. 기록 시점의 설치 버전은 **0.4.1**, 업데이트 상태는 `waiting-for-zotero-exit`입니다. 실제 새 버전 활성화는 확인하지 않았습니다.

[기능 대조표](feature-parity.md)의 차이와 조건을 유지합니다. 외부 데이터 제공자, 읽기 데이터 저장 방식, 원본 화면·모든 옵션까지 동일하게 복제됐다는 의미는 아닙니다. 주석 병합은 개별 주석을 가리키는 기존 노트 링크를 자동 재작성하지 않으며, 합쳐진 나머지 주석은 휴지통에서 복원할 수 있습니다.
