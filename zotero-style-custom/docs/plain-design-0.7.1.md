# Style Custom 0.7.1 장식 제거

네일아트 이미지·손톱·반짝이 아이콘은 소스와 UI 자산에 없었습니다. 장식적으로 보일 수 있는 기본 보라/금색 강조, 큰 둥근 모서리, 그림자, 점무늬 배경과 장식용 글꼴을 제거했습니다. 흰색·회색 기본색, 최대3px 모서리, 시스템 글꼴을 사용합니다. 리더 메뉴와 세로 탭도 평평한 형태로 맞췄고 별점의 금색 채색과 상태의 둥근 색 배지를 제거했습니다.

별점·상태·읽기 진행률·태그·주석 색상은 실제 정보라 유지합니다. 기존 사용자가 저장한 카드 색상이나 문헌 데이터는 지우지 않았습니다. 새 카드 기본색은 무채색입니다. 기존 디자인 문서는0.7.0의 과거 기록이며 현재 미리보기는 이 버전으로 갱신했습니다.

[현재 미리보기](design-preview.html). 백그라운드 테스트265개와 임시 프로필 설치기11개 통과; 마지막 인라인 표시 수정 후 관련86개 테스트 재확인. XPI18개 파일이 소스와 일치합니다. SHA256 `8106100847302527fd6df54ae1331dce7746065168cabb3836ce4ae16a6c7587`.

기록 시점 설치 버전은0.4.1, 새 버전은 `waiting-for-zotero-exit`입니다. 사용자 화면을 띄우거나 앱을 재실행하지 않았고 실제 활성화·시각 검증은 하지 않았습니다. [설치 상태](installation-status.json)의 실시간 상태 파일을 참고하세요.
