# Style Custom 0.5.1 수정 기록

0.5.0의 연구 작업 패널과 지표 자동화를 유지하면서 저장·취소·창 종료 경계에서 재현한 문제를 수정했습니다. 두 에이전트가 문헌/작업 패널과 리더/읽기 기록을 각각 담당했고, 루트에서 비동기 작업과 설치기를 통합 검증했습니다.

| 영역 | 수정한 동작 |
| --- | --- |
| 메모·노트 | 저장을 기다리는 동안 이어 쓴 초안을 보존합니다. 이전 저장 실패가 뒤에 성공한 메모를 덮어쓰지 않습니다. 다른 창에서 같은 값을 다시 저장하는 경우도 구분합니다. |
| 캔버스 | 초안 복원 때문에 보드 선택 표시와 실제 작업 대상이 달라지지 않습니다. |
| 탭 그룹 | 아직 로드되지 않은 기존 탭도 저장한 페이지로 복원합니다. 복원 중 원래 창이나 대상 창이 닫히면 이후 열기·선택을 중단합니다. |
| 읽기 시간 | 포커스를 잃거나 창을 닫기 직전의 짧은 활동 구간도 원래 문헌·페이지에 한 번만 기록합니다. 무활동·절전 시간 제한을 유지합니다. |
| AI 취소 | 응답이 오지 않는 요청도 즉시 취소 처리합니다. 늦게 도착한 네트워크 취소 핸들러도 실행하며 다음 요청을 막지 않습니다. |
| 메타데이터 | 묶음에 삭제된 항목이 있어도 나머지 문헌의 인용 수 조회를 계속합니다. |
| 종료 처리 | 창 종료로 인용 수 재시도 타이머가 멈추지 않습니다. 일부 정리나 저장에 실패해도 나머지 관찰자·열·패널을 해제하고 오류를 보고합니다. |
| 작업 패널 | 앱 밝게/어둡게 전환과 선택 사항인 읽기 시 수정일 갱신 설정을 실제 버튼·옵션에 연결했습니다. |
| 백그라운드 업데이트 | 대기 만료·취소·실행 PID를 상태 파일에 기록합니다. 다음 설치 시도 전과 실제 교체 직전에 취소·시간 제한을 확인합니다. 잠금 획득 후 설치 버전을 다시 읽어 더 최신인 버전을 보존합니다. 교체가 시작된 뒤에는 중간 취소하지 않습니다. |

검증: Node/DOM 테스트 195개와 임시 프로필 설치기 테스트 11개 통과. 설치기 테스트는 실행 중인 앱 보존, 백업, 다른 설정·레지스트리 보존, 잘못된 해시·ID 거부, 교체 실패 시 복구, 최신 버전 보존, 취소·시간 초과를 검사했습니다. 48개 원본 설정 항목과 7개 추가 워크플로의 구현·테스트 연결도 유지했습니다.

검증한 XPI의 런타임 파일 18개를 소스와 바이트 단위로 대조했습니다. SHA-256: `6b7c354864b3b3b83586d47ea62c8854a34187d0e313d0e5373ace6b076ca209`.

사용자 UI를 제어하거나 추가 Zotero 프로세스를 실행하지 않았습니다. 이 결과는 실제 Zotero 화면에서 새 버전이 활성화됐다는 증거가 아닙니다. 패키지·설치 버전과 대기 프로세스 정보는 [설치 기록](installation-status.json), 검증 수치는 [검증 기록](hardening-verification.json)을 참고하세요. 실제 대기·교체 결과는 설치 기록의 `liveUpdateStatus` 파일이 갱신합니다. 이전 0.5.0 기록은 과거 검증 자료로 유지합니다.
