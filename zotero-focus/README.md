# Zotero Focus

Zotero의 긴 제목을 마우스로 빠르게 읽고, 읽기 상태·별점·태그를 관리하는 독립 플러그인입니다. 계정, 결제, API 키 없이 로컬에서 작동합니다.

현재 버전은 **0.1.0**, 지원 대상은 **Zotero 9**입니다. 개발 검증 대상은 macOS의 Zotero 9.0.6입니다. 기존 ZotPoP와 별도 패키지이며, Ethereal Style의 소스를 가져오지 않고 구현했습니다.

## 설치

1. 이 폴더에서 `npm run build`를 실행하면 `build/zotero-focus-0.1.0.xpi`가 생성됩니다.
2. Zotero → 도구 → 플러그인 → 톱니바퀴 → **파일에서 플러그인 설치…**에서 XPI를 선택하세요.
3. 논문 목록의 긴 제목 위에 마우스를 올려보세요. 기본적으로 **0.2초 뒤, 초당 180px**로 움직입니다.

이 개발 버전의 업데이트는 새 XPI를 직접 설치하는 방식입니다. 아직 자동 업데이트 서버는 없습니다. Zotero 9가 HTTPS 업데이트 주소를 필수로 요구하므로 매니페스트에는 예약 도메인 `updates.invalid`를 명시했습니다. Zotero의 ‘업데이트 확인’은 이 플러그인의 업데이트를 조회하지 못할 수 있지만 읽기·별점·제목 스크롤 기능은 네트워크 없이 작동합니다.

제목이 끝에 도달하면 잠시 멈췄다가 반복합니다. 마우스를 떼거나 목록을 스크롤하거나 항목을 클릭하면 원래 위치로 돌아갑니다. 아이콘·기울임꼴·태그 색상·행 선택은 Zotero가 렌더링한 상태를 유지합니다. 시스템의 ‘동작 줄이기’가 활성화되어 있으면 움직임 대신 전체 제목 툴팁을 사용합니다.

이미 설치된 Style은 자동으로 비활성화하거나 제거하지 않습니다. Focus의 열은 `Focus ·` 접두어로 구별할 수 있습니다. 이 개발 작업은 사용자의 Zotero 프로필에 자동 설치하지 않습니다.

## 사용

- **읽기 상태:** 문헌을 선택한 뒤 우클릭 → Zotero Focus → 안 읽음 / 읽는 중 / 읽음.
- **별점:** 우클릭 → Zotero Focus → 별점 → 1–5점 또는 별점 지우기.
- **여러 문헌:** 여러 행을 선택한 상태에서 같은 메뉴로 일괄 변경합니다. 편집할 수 없는 라이브러리는 변경하지 않습니다.
- **열 표시:** 열 제목을 우클릭하여 `Focus · 읽기 상태`, `Focus · 별점`, `Focus · 태그`를 표시하거나 숨길 수 있습니다. 제목 열을 넓히지 않아도 마우스 스크롤은 작동합니다.
- **스크롤 설정:** Zotero 설정 → Zotero Focus에서 기능을 켜거나 끄고, 시작 대기 시간과 속도를 바꿀 수 있습니다. 문헌 우클릭 메뉴에서도 켜고 끌 수 있습니다.
- **태그 필터:** 설정의 태그 접두어를 빈칸으로 두면 일반 태그를 모두 표시합니다. `#`을 입력하면 `#`으로 시작하는 태그만 표시하고 표시할 때 `#`을 생략합니다. 원본 태그는 바뀌지 않습니다.

## 저장 방식

상태와 별점은 다음과 같은 일반 Zotero 태그로 저장합니다.

| 의미 | 태그 |
|---|---|
| 읽는 중 | `zotero-focus:status:reading` |
| 읽음 | `zotero-focus:status:done` |
| 별점 4 | `zotero-focus:rating:4` |
| 안 읽음·별점 없음 | 해당 메타데이터 태그 없음 |

Zotero의 일반 동기화에 포함됩니다. 이 태그들은 Focus 태그 열에서는 숨기지만 Zotero 기본 태그 목록에서는 보입니다. 제목·저자·DOI·Extra나 다른 플러그인의 메타데이터는 수정하지 않습니다. 같은 필드에 중복된 유효 태그가 있으면 가장 진행된 읽기 상태와 가장 높은 별점을 표시하며, 해당 필드를 변경할 때 정리합니다. 모르는 미래 버전의 값은 보존합니다.

플러그인을 제거해도 저장한 태그는 남습니다. 없애려면 제거 전에 해당 문헌을 선택해 ‘안 읽음’과 ‘별점 지우기’를 적용하세요. 기존 Style의 별점·읽기 상태는 자동으로 옮기지 않습니다.

## 이번 버전의 범위

구현한 기능은 **제목 마우스 스크롤, 수동 읽기 상태, 별점, 태그 열**입니다. GitHub의 Ethereal Style 전체 기능을 복제한 버전은 아닙니다. IF/JCR 등 저널 지표, 읽기 시간·페이지별 진행률, 중첩 태그 탐색기, 그래프, PDF 테마와 뷰 그룹은 아직 구현하지 않았습니다. 읽기 상태를 PDF 열기만으로 자동 변경하지 않습니다.

## 개발과 검증

런타임 외부 의존성은 없습니다. 단위 테스트에는 Node.js 18 이상, XPI 빌드에는 Python 3가 필요합니다.

```sh
cd zotero-focus
npm test
npm run build
```

`scripts/build.py`는 고정 타임스탬프로 XPI를 생성하고, 모든 런타임 파일·버전·압축 내용을 확인합니다. 의도적으로 불완전한 패키지가 검증에서 실패하는지도 확인합니다.

실제 앱 검증용 `scripts/smoke.py`는 별도의 임시 프로필과 임시 데이터 디렉터리를 강제로 지정하고, 테스트 문헌만 만듭니다. 실제 사용자 라이브러리나 기존 Zotero 프로필에는 연결하지 않습니다. 지원 API 조사와 실행 결과는 `docs/`를 참고하세요.

검증 결과: 자동 테스트 **29개 통과**. macOS Zotero **9.0.6**의 별도 프로필에서 실제 XPI 로딩, 메뉴를 통한 저장, 실패 시 데이터 복원, 서식이 있는 긴 제목 스크롤, 비활성화·재활성화를 확인했습니다. 앱 검증은 헤드리스 환경의 실제 Zotero DOM을 대상으로 했습니다. [실행 결과](docs/smoke-result.json)에는 검증한 XPI의 SHA-256이 포함되어 있습니다.

참고 문서: [Zotero 플러그인 API](https://www.zotero.org/support/dev/zotero_7_for_developers), [Ethereal Style 기능 목록](https://github.com/MuiseDestiny/zotero-style).
