# ZotPoP 0.37.0 검색 확장 결과

2026-09-20 KST. 설치본을 0.37.0으로 업데이트하고 실제 Zotero 화면에서 검증했다. 앞선 감사의 검색 결함을 수정하고, 선택형 통합 검색과 저자 ID 검색, 2,000건 수집을 추가했다. **기능 확장과 회귀 검증은 완료했지만, 모든 검색에서 Publish or Perish와 완전히 동등하다는 주장은 하지 않는다.** 새 엄격 비교는 4개 사례 중 2개만 통과했다.

## 사용할 수 있는 기능

- **통합 검색 소스 선택:** 검색창 아래에서 OpenAlex·Crossref·Europe PMC·arXiv·PubMed·Semantic Scholar·Google Scholar 중 원하는 소스를 고른다. 기본은 기존 네 소스다. Google Scholar는 설치된 PoP 엔진이 있으면 사용한다. 선택은 최근 검색과 함께 저장되며 다른 소스 조합의 캐시를 섞지 않는다.
- **대량 검색:** 입력한 최대 결과 수를 화면에서 200건으로 낮추던 코드와 검색원별 200건 상한을 제거했다. 1,000·2,000건을 페이지별로 수집하고, 중복을 합쳐 부족해지면 가능한 검색원을 추가 조회한다. 사용자가 지정한 상한은 전체 데이터베이스의 완전한 수집을 의미하지 않는다.
- **저자 ID 검색:** OpenAlex 또는 OpenAlex가 선택된 통합 검색에서 ORCID나 OpenAlex 저자 ID/URL을 입력할 수 있다. 체크섬이 잘못된 ORCID, 잘못된 ID, 지원하지 않는 복합 ID 조건은 이름 검색으로 변환하지 않고 거절한다. ID 검색은 레코드의 실제 저자 식별자를 검증한다.
- **검색식:** PubMed와 Europe PMC의 제목 검색에서 괄호·AND·OR·NOT·구절의 의미를 유지한다. PubMed에 전체 제목을 붙여 넣을 때 `in` 같은 색인되지 않은 불용어로 결과가 사라지던 문제를 수정했다. 다른 검색원도 지원하는 범위를 명시하고, 지원할 수 없는 식은 조용히 다른 의미로 실행하지 않는다.
- **논문 식별:** ± 부호·부등식·위첨자·아래첨자가 다른 논문을 합치지 않는다. 성은 같지만 이름이 다른 저자의 같은 제목도 합치지 않는다. 프리프린트와 출판본 연결에는 명시적인 관계 또는 제목·저자·연도 근거가 필요하다.
- **오류와 출처:** 서비스별 인증 정보를 분리해 OpenAlex 키가 Crossref로 전달되는 오류를 막았다. 보완한 인용 수의 출처를 남긴다. 일시적인 전송 실패는 횟수가 제한된 재시도로 복구하고, 중단·실패 전에 받은 결과는 불완전한 검색으로 보존한다.

`Sheila Ingemann`이 `Sheila I. Stewart`와 일치하던 오류도 수정했다. 기존 69건의 저장 검색은 원본 파일을 바꾸지 않고 다시 검사해, 조건에 맞지 않는 2건을 화면에서 제외하고 **67건**을 표시했다. 이름 검색만으로 동일 인물을 확정할 수는 없으므로 정확한 인물 지정에는 ID를 쓰는 편이 낫다. 공급자가 잘못 연결한 저자 프로필까지 이 수정이 보증하지는 않는다.

## 실제 검색 검증

최종 소스 SHA-256을 기록한 직접 실행이다. API 키 없이 인용·저널·기관 보완을 끄고 검색 수집 자체를 확인했다. [요청·시간·검색원별 상태](live-summary.json).

| 사례 | 결과 | 시간 및 판정 |
|---|---|---|
| PubMed에 `CRISPR Cas9 assisted recombineering in Lactobacillus reuteri` 전체 제목 붙여넣기 | DOI `10.1093/nar/gku623` 1건 | 1.832초, 기존 0건 문제 해결 확인 |
| Europe PMC 제목 `recombineering OR "genome editing"` | 20건 | 4.127초, 정상 반환 |
| PubMed 제목 `recombineering NOT yeast` | 20건 | 2.878초, 정상 반환 |
| Geobacillus, Crossref+Europe PMC+PubMed 통합, 최대 1,000건 | **1,000건** | 첫 결과 1.192초, 완료 24.893초, 소스 오류 없음 |
| OpenAlex 저자 ID `A5086928770` | HTTP 429 | 실데이터 검증 불가. 실패를 통과로 계산하지 않음 |

첫 사전 실행에서는 PubMed의 일시적인 `fetch failed`가 있었다. 이를 계기로 전송 재시도 및 재시도 중 취소를 추가 검증했고, 최종 실행에서는 전체 제목의 대상 논문을 찾았다. 첫 실행과 최종 실행 원본은 `build/search-expansion-20260920/`에 별도로 보존했다. OpenAlex ID 경로는 실제 공급자 응답을 본뜬 테스트로 검증했지만, 이번 비인증 실조회는 한도 때문에 검증하지 못했다.

2,000건은 **실제 HTTP를 대체한 페이지 응답 테스트**로 확인했다. 통합 검색과 Preprints에서 검색원들이 전부 같은 논문을 반환하는 경우, 여러 ID가 연결돼 최초 후보 2,200개가 734개로 합쳐지는 경우에도 최종 2,000건을 채우는 검증을 포함한다. 2,000건을 모두 실제 서비스에서 내려받았다는 뜻은 아니다.

## 같은 날 PoP와의 엄격 비교

설치된 공식 PoP CLI로 새 참고 결과를 받았다. 검색원·검색 필드·정렬·상한·수집 시각·명령·해시를 기록했다. Scholar 후보도 PoP 엔진을 사용하므로 **독립적인 Scholar 크롤러의 동등성 검증은 아니다**. [참고 결과 수집 기록](capture-summary.json), [상세 판정](comparison.md), [비교 수치와 불일치](comparison-summary.json).

이번 판정은 단순히 상위 10건을 상위 30건 안에서 찾는 것으로 끝나지 않는다. 전체 상한의 일치율, 같은 크기의 상위 결과와 순서, 식별 정보의 모순·누락, 알려진 대상 논문, 필드 검증 가능 여부를 따로 검사한다. 관련성에 대한 사람의 판정은 새로 만들지 않았다.

| 사례 | PoP 원본 → ZotPoP | 상위 10건과 순서 | 엄격 판정 |
|---|---:|---|---|
| Crossref / Geobacillus / 최대 1,000건 | 1,000 → 1,000 | 일치 | **미통과:** 원본 행 일치 971/1,000, 메타데이터 차이·누락 |
| PubMed / 알려진 논문 / 최대 10건 | 1 → 1 | 일치 | 통과 |
| Scholar / 알려진 논문 / 최대 10건 | 1 → 1 | 일치 | 통과 |
| Scholar / Sheila Ingemann Jensen / 최대 30건 | 30 → 29 | 일치 | **미통과:** 중복 합침과 생략된 저자 정보 때문에 전체 검증 불가 |

Crossref 참고 결과에는 같은 DOI의 중복 14건이 있었다. 고유 DOI 기준으로는 **971/986 = 98.48%**를 찾았다. 원본 행 기준 97.1%와 고유 DOI 기준 98.48%는 서로 다른 수치이며, 후자를 이용해 엄격 판정을 통과로 바꾸지 않았다. 고유 DOI 15개가 이 후보 상한 안에 없는 이유를 모두 해결했다고 주장하지 않는다. 순위 동률·오프셋 페이지 변동 등의 가능성은 있지만, 이번 실행만으로 원인을 확정할 수 없다.

메타데이터 차이에는 PoP가 생략한 기관·집단 저자를 ZotPoP가 보존한 사례, 공급자가 출판 연도를 주지 않은 사례가 있다. 모든 차이가 ZotPoP의 오류라는 뜻은 아니며, 반대로 모든 차이를 무시해서도 안 된다. Scholar의 29건은 같은 제목·저자에 해당하는 `Consortia based production of biochemicals` 두 기록을 합친 결과다. 원본·후보의 저자 목록 상당수가 `...`로 생략돼, 엄격한 저자 검증을 완전 통과라고 보고하지 않았다.

## 검증 및 실제 설치

- `npm run test:offline`: **277개 통과, 실패·건너뜀 0개**. 새 검색 확장 테스트 29개를 포함한다.
- Query, adapter, evaluator 각 작업의 게이트를 부모 에이전트가 다시 실행했다. 실제 의미를 검증하는 Boolean 진리표, 잘못된 인증 전달, 잘못 합쳐지는 논문, 2,000건 중복·추가 수집, 취소를 포함한다.
- 엄격 평가기의 부정 대조군은 9/30·200/2,000 잘림, 순서 뒤집힘, DOI만 유지한 잘못된 제목·저자, 필드 검증 불가, 오래된 증거를 검출한다. 과거 비교는 `--historical-replay`로 명시해서만 재생한다.
- 0.37.0 XPI를 실제 Zotero에 설치하고 설치 파일이 최종 소스와 같은지 확인했다. 기존 검색 조건 보존, 7개 검색원 선택 UI 및 선택 저장, 캐시 오탐 제외를 확인했다.
- 실제 Gecko DOM에서 기본 이동 0개, hover 이벤트 후 해당 셀만 45px 이동, 이탈 후 이동 0개를 확인했다. 제어된 synthetic mouse 이벤트를 사용했다. [설치·화면 동작 증거](native-verification.json).

## 남아 있는 범위와 제한

OpenAlex 요청 한도, Scholar CAPTCHA/생략된 메타데이터, Semantic Scholar 관련도 API의 후보 한도 같은 공급자 제약은 남는다. 필요할 때 명시적으로 불완전한 결과로 표시한다. 혼합 검색의 인용 지표는 단일 인용 데이터베이스에서 계산한 지표와 같다고 보장할 수 없다.

이번 확장은 현재 무료 검색원과 설치된 PoP Scholar 연동을 대상으로 한다. Scopus·Web of Science·Lens·Scholar Profile의 새 어댑터나 기관 구독 인증을 추가한 것은 아니다. PoP 자체도 외부 검색원의 범위·문법·제한을 따른다. [PoP 공식 검색원 문서](https://harzing.com/resources/publish-or-perish/manual/using/data-sources), [저자 검색 안내](https://harzing.com/resources/publish-or-perish/manual/using/use-cases/author-search).

재현 명령: `npm run test:offline`, `node scripts/verify-comparison.mjs --historical-replay`. 새 실조회는 `node scripts/search-expansion-capture.mjs`, `node scripts/search-expansion-compare.mjs`, `node scripts/search-expansion-live.mjs`로 실행한다. 참고 캡처·비교 설정·원본 결과는 로컬 `build/search-expansion-20260920/`에 있으며, 소스 JSON 요약에는 초록·임시 접근 URL을 복제하지 않았다. 다음 실조회는 공급자 결과와 쿼터에 따라 달라질 수 있다.


## 추가 요청: 0.37.1 열 순서 드래그앤드롭

열 머리글을 다른 머리글의 왼쪽·오른쪽으로 끌어 순서를 바꿀 수 있다. 드롭 위치를 표시하고, 머리글·열 너비·본문을 같은 필드 기준으로 이동한다. 순서는 다시 열 때 복원되며 새 검색 결과와 상태 업데이트에도 적용된다. 일반 클릭 정렬, 가장자리 너비 조절, 행 선택과 링크, hover 롤링은 유지한다.

0.37.1을 실제 Zotero에 설치했다. 실제 Gecko 표에서 DragEvent/DataTransfer를 발생시켜 연도 열 이동,67개 행과 열 너비 정합,재열기 후 유지,클릭 정렬,너비46→58px 조절을 확인했다. 검증 후 사용자 원래 순서·너비·검색 입력·가로 스크롤 위치를 복원했다. OS 자동화 도구의 드래그는 문서에 mouse 이벤트가 전달되지 않아 성공으로 계산하지 않았고, 검증 방법을 [증거 JSON](columns-native-verification.json)에 명시했다.

열 관련9개 검증이 추가되어 최종 오프라인 테스트는 **286개 통과, 실패·건너뜀0개**다. 검색 엔진은0.37.0에서 검증한 동일 소스이며, 앞 절의 PoP비교2/4통과 및 API한도 제약은 그대로다. Unlazy 최종 게이트15개 충족, 미충족0개, 포기0개.
