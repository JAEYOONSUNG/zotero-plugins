# JCR 실제 그룹·카테고리 탐색 — Style Custom 0.51.0

0.50.3은 설치됐으나 OpenAlex 분류 오류와 명칭만 수정했습니다. 사용자가 요구한 [JCR Browse Categories](https://jcr.clarivate.com/jcr/browse-categories)의 실제 그룹·카테고리 화면은 구현하지 않았습니다. 0.51.0은 **저널 지표 탭의 기본 화면을 JCR 그룹 → 카테고리 → 해당 저널 목록으로 변경**합니다.

## 원본과 데이터 검증

Aside의 접근 가능한 JCR 화면에서 그룹, 전체 카테고리 표, 저널 표 114페이지를 읽었습니다. JCR 2026 발표, 지표 연도 2025, 원본 갱신 표시 2026-06-17, 수집일 2026-09-20입니다. 현재 사이트를 계속 조회하는 기능이 아니라 날짜가 명시된 수집 자료입니다. 로그인 정보나 세션 토큰은 저장하지 않았습니다.

그룹의 저널 수는 JCR 화면에 표시된 값을 보존합니다. 모든 그룹에서 이 수는 소속 카테고리의 저널 수 합계와 같으며, 여러 카테고리의 중복 소속을 포함합니다. 예를 들어 Agricultural Sciences는 원본 표시 475종, 중복을 제거한 집합은 445종입니다. 445로 바꾸면 원본 화면과 달라집니다.

공식 순위·Q·백분위는 선택한 카테고리의 값만 사용합니다. 접힌 행에 표시되는 대표 순위를 다른 카테고리에 복사하지 않습니다. 여러 그룹에 속한 카테고리와 여러 카테고리에 속한 저널을 모두 유지했습니다. `<0.1` JIF 619건, JIF `N/A` 49건, 순위 없는 지표 문맥 3,012건을 그대로 보존했습니다. DOM 열 이름 `jif2019`는 화면의 실제 헤더인 **2025 JIF**와 구분했습니다.

## 화면과 동작

기본 화면의 21개 그룹을 펼쳐 실제 카테고리를 선택합니다. 전체 254개 카테고리 표도 제공하며 기본 정렬은 JCR처럼 저널 수 내림차순입니다. 카테고리를 선택하면 실제 소속 저널, JIF, 카테고리별 공식 순위·Q·백분위가 나타납니다. 검색, 정렬 방향, 페이지당 25·50·75·100·200개, 뒤로가기를 지원합니다. 저널 검색 버튼은 해당 저널명을 ZotPoP 논문 검색에 전달합니다.

기존 OpenAlex 주제 탐색은 명시적으로 선택하는 별도 모드입니다. 과거 OpenAlex 필터가 저장돼 있어도 새 JCR 기본 화면을 가로채지 않습니다. JCR 자료 로딩 실패는 오류로 표시합니다. 문헌 선택 도구는 JCR 화면에서 숨기고 비활성화하며 선택한 문헌 자체는 보존합니다.

실제 Workbench·JCR 코드와 전체 자료를 격리된 headless Chrome에서 렌더링했습니다. 1440/620 px의 그룹·그룹 확장·전체 카테고리·저널 화면 8개와 가로 스크롤 화면 3개를 확인했습니다. 좁은 표는 내부 가로 스크롤을 사용합니다. 이는 실제 Zotero 안에서의 렌더링 검증과 구분합니다.
